TIER 1 • PRESENTATION & CLIENTS

Desktop & Multi-Channel Shells

  • Tauri v2 Desktop Shell: Frameless Next.js 16 UI with primary dashboard, live token stream, and visual diff viewer.
  • Voice Micro-HUD: Translucent floating HUD window accessible via global shortcut (Ctrl+Shift+Space) with local STT.
  • Terminal Companion: Standalone compiled binary krypton-cli using React 18 + Ink for terminal users.
  • Omni-Channel Gateway: Real-time bridge connecting external bots (Telegram, Discord, Slack, WhatsApp, Signal).

TIER 2 • IPC & SUPERVISION

Host Supervision & Multi-Transport

  • Rust Native Supervisor: Discovers, spawns, and health-monitors the standalone krypton-daemon child process.
  • Clean Teardown Cascade: Enforces graceful SIGTERM → 3,000ms grace → forced process tree kill.
  • Platform IPC Endpoints: Windows Named Pipe (\\.\pipe\krypton-ipc) and POSIX Domain Socket for low latency.
  • WebSocket Streaming: Full-duplex RFC 6455 socket on port 18789 broadcasting token deltas, logs, and task DAG events.

TIER 3 • AUTONOMOUS ENGINE

Actor Runtime & Dynamic Planning

  • Autonomous Step Loop: Observe → Reason → AST Validate → Execute → Verify → Checkpoint.
  • Recursion & Budget Caps: Hard depth ceiling (≤3), concurrency limit (≤5), 50% child token budgeting, 60s timeout.
  • Dynamic TaskTree DAG: Topological execution with automated replanning, downstream freezing, and TODO.md sync.
  • Stealth AXTree Browser: CDP Accessibility Tree blind navigation with numeric IDs ([id=1]) & Bézier humanizer.

TIER 4 • SECURITY & ISOLATION

AST Jails, Worktrees & Vault

  • AST Safety Linter: Pre-execution static analysis blocking dangerous imports, shell escapes, and root drive writes.
  • OS Subprocess Jails: Windows Job Objects (512MB RAM cap, CPU priority throttle) and POSIX rlimit.
  • Krypton-VCS Worktrees: Zero user branch pollution; atomic conventional semantic commits; deterministic hard rollback.
  • Secret Vault & Event Sourcing: OS Keyring + AES-256-GCM encrypted vault with append-only events.jsonl ledger.
